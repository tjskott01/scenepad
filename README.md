# ScenePad

A phone-first stage controller (installable PWA) for the Fractal Audio Axe-Fx III, built on the Web MIDI API and the published
"Axe-Fx III MIDI for Third-Party Devices" SysEx spec (rev 1.4). Static files only, no backend.

Independent fan project. Not affiliated with or endorsed by Fractal Audio Systems. Open `?demo` for a simulated unit.
